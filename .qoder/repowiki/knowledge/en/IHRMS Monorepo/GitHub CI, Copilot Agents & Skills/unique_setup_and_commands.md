Backend tests use `python ops/run_tests.py --backend sqlite|sqlserver`; the wrapper provisions disposable DB/media so CI never touches production databases. The SQL Server workflow requires installing Microsoft's ODBC driver 18 (`msodbcsql18 unixodbc-dev`) before running. Backup safety tests run under PowerShell via `./ops/backup/Test-BackupSafety.ps1 -Kind Full|Log -Scenario Express|Standard|Failure`.
