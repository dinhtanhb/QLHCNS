Two unrelated artifact trees sit at the repo root with no executable code:
- `graphify-out/` — output of the external Graphify tool. `manifest.json` is the index mapping every source file path to its `mtime`, `seen`, `ast_hash`, and `semantic_hash`. `cache/ast/<version>/` holds one SHA256-named JSON blob per analyzed file keyed by `cache/stat-index.json`; `cache/semantic/<hash>/` mirrors semantic payloads. `.graphify_analysis.json` contains community detection results grouping symbols like `src_apps_*_models_employee` into clusters; `graph.html` / `graph.json` are the rendered dependency graph and data; `.graphify_root` records the workspace root used during analysis.
- `outputs/` — produced deliverables for the IHRMS analytics dashboard. Dated subdirectories (`ihrms-analytics-dashboard-20261009`, `ihrms-dashboard-final-20261009`) each contain an Excel workbook (`IHRMS_Analytics_Dashboard.xlsx`), a PNG screenshot (`Dashboard.png`), and an NDJSON inspection log (`*.xlsx.inspect.ndjson`). `design-review-20261021/` holds design-review screenshots under `evidence/` plus `index.html` and `themes.html`. `mobile-app-plan-20261021/` captures before/after prototype screenshots across device widths and themes. `home-dashboard-options.html` is a standalone HTML asset.
Dependency direction is one-way: these directories are consumed-only outputs regenerated when the source tree changes.
