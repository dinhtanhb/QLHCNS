Flat collection of independent CLI entry points plus three small sub-packages, each owning one operational concern with a one-way dependency on `src/apps.*` models and `config.settings`:
- Top-level `run_*.py` / `check_*.py` / `audit_*.py` scripts are self-contained Django-aware CLIs: they bootstrap `DJANGO_SETTINGS_MODULE='config.settings'`, set `APP_ENV='test'`, insert `root/src` into `sys.path`, call `django.setup()`, then import ORM models to seed fixtures or assert rendered output.
- `ops/run_tests.py` is the canonical test runner: it selects a backend (`sqlite` | `sqlserver` | `configured`), creates an in-memory SQLite DB or a disposable `test_ihrms_<uuid>` SQL Server database (refusing reuse of the app DB), sets `MEDIA_ROOT` under `tempfile.TemporaryDirectory`, forces `locmem` email backend, and wraps `DiscoverRunner` with a non-empty-suite guard. `ops/Run-Tests.ps1` is a thin Windows wrapper that locates the venv Python, forwards `--backend` and labels, and parses the 'Found N test(s).' line to reject zero-discovery runs.
- `ops/run_browser_uat.py` and the many `run_*_uat.py` scripts launch Playwright against a `LiveServerThread` on a fresh disposable DB, create synthetic fixtures via ORM, drive Edge headless, capture screenshots to `<output>/screenshots`, and write `<output>/browser-result.json`. A shared `server_readiness_browser.run` helper is invoked from both the main flow and individual UAT runners.
- `ops/check_ui_contrast.py`, `ops/audit_button_kinds.py`, `ops/render_ui_components.py`, `ops/capture_ui_screenshots.py`, `ops/layout_waivers.json` form the UI-design-audit layer: parse CSS tokens from `src/static/css/ui_tokens.css`, crawl templates/live pages via Playwright CDP, compare button kinds/sizes against a JSON contract, and write machine-readable reports outside the repo.
- `ops/check_ui_menu_links.cjs` is a Node 22+ script using only stdlib modules to launch Edge headless via CDP and validate pointer-click navigation against a synthetic-cases JSON file.
- `ops/reset_qa_data.py` is a guarded SQL Server-only resetter: rejects any DB name not matching `(qlhcns|ihrms)_uat_[A-Za-z0-9_]+|qlhcns_reset_preview_20261009`, requires a `.bak` outside the repo, enforces an `IHRMS_DISPOSABLE_QA=YES` extended property, clears all but a whitelisted catalog of 107 tables, and seeds exactly 33 users (3 per role) while writing credentials to an unused absolute path.
- `ops/backup/` contains PowerShell + T-SQL scripts (`Backup-FullDatabase.ps1`, `Backup-TransactionLog.ps1`, `Test-BackupSafety.ps1`, `Setup-RecoveryModel.sql`) orchestrated by Windows Task Scheduler; `ops/probes/` holds a single Python probe (`booking_status_validation.py`); `ops/scheduler/` has reminder runners invoked by Task Scheduler.
