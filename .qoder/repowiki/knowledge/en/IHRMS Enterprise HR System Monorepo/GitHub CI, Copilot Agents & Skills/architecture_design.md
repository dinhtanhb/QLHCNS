Two layers coexist under `.github/`:
- `workflows/`: GitHub Actions definitions. `ci.yml` runs on push/PR to `main` with three jobs — backend (Python 3.12 + SQLite via `ops/run_tests.py --backend sqlite`, pip/npm audit, Django `check` + migration dry-run), frontend (Node 22, `npm ci`, CSS build), and backup-command-tests (PowerShell invoking `ops/backup/Test-BackupSafety.ps1`). `sqlserver-regression.yml` is a weekly cron job that spins up an MSSQL 2022 service container and re-runs the same test harness against SQL Server.
- Copilot extension surface: `copilot-instructions.md` is the top-level directive; `agents/*.agent.md` declare per-domain agents (HRM backend, portal UI export, security auditor); `instructions/*.instructions.md` provide domain-specific guidance (backend ORM, Tailwind templates); `skills/*/SKILL.md` packages reusable Copilot skills (RBAC audit, HRM module scaffold, MSSQL optimization, SQL Server ops check). `hooks/` and `prompts/` are reserved but empty today.
Dependency direction is one-way: workflows invoke repo scripts (`src/manage.py`, `ops/run_tests.py`, `ops/backup/Test-BackupSafety.ps1`) and never import each other; Copilot assets are read-only by the IDE.
