Two parallel skill trees mirror each other: `.agents/skills/<name>/SKILL.md` for the generic agents framework and `.claude/skills/<name>/SKILL.md` for Claude Code. Each skill is a self-contained directory whose single `SKILL.md` frontmatter declares `name`, `description`, and optional flags like `disable-model-invocation`. The top-level `ask-matt` skill acts as a router over all others, defining the canonical main flow (`grill-with-docs → to-spec → to-tickets → implement/implement-spec → tdd → code-review → pr → retro`) plus on-ramps (`triage`, `diagnosing-bugs`, `wayfinder`), vocabulary layers (`domain-modeling`, `codebase-design`), standalone primitives (`grill-me`, `grilling`, `prototype`, `research`, `to-questionnaire`, `wizard`, `wait-what`, `teach`, `writing-for-agents`), and phase-boundary protocol (`clear`, `handoff`, subagent, `compact`). Cross-skill orchestration happens by invoking sibling skills via `/name` paths rather than shared code; state between phases is carried in repo artifacts like `GLOSSARY.md`, ADRs, `.scratch/<feature>/issues/`, and prototype branches under `prototype/<name>`.
